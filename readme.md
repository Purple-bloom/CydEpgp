# EPGP Helper Addon For EPGP WITH GP BIDDING
Supports a prio import and sorting in the format provided by 

## What this addon does:
- It can import prios, characters and settings from https://github.com/Purple-bloom/EPGPHelper
- It will automatically open up a Window to post items for bids when looting
- It will autoloot BoEs to yourself (optional, can be changed in the settings)
- It will display a list of bids received and also display the character name and prio
- It will automatically downgrade / change bids according to the imported prio threshholds.
- It will add a minimap button, which opens the controlPanel. From there you can export to the website, award EP, check if all characters in the raid are also in the system, change settings etc.


"hidden" Slash commands:

/pap will print all prios of all current raid members in the raid chat
/getRaidMembers will display a popup with an editBox pre-filled with all currently online raid members for easy copying. Might be useful

Intended for use with the CydEpgp webserver + backend server here:
